# خطة بناء موقع ذهب ومعادن ثمينة + لوحة تحكم كاملة

## ملاحظة مهمة قبل البدء
هبني نفس **الهيكل والأقسام والوظائف** الموجودة في الموقع المرجعي، لكن **مش هنسخ** اللوجو أو الصور أو النصوص أو اسم العلامة التجارية الخاصة بـ BTC، لأنها ملك الشركة. الموقع هيكون بتصميم أصلي بطابع فخم (ذهبي/أسود)، ونصوص وصور مؤقتة، وانت تقدر تغير كل حاجة بعد كده من لوحة التحكم (الاسم، اللوجو، الصور، النصوص، الأسعار).

## اللي هيتعمل في الموقع (الواجهة)

1. **نافذة منبثقة** عند الدخول (رسالة + زر رابط) — قابلة للتشغيل/الإيقاف.
2. **سلايدر رئيسي** (4-5 شرائح): صورة، عنوان، وصف، زر — مع نسخة للموبايل.
3. **شريط أسعار الذهب والفضة** بالدولار للأوقية.
4. **جدول أسعار المعادن** (بيع / شراء بالجنيه): جنيه ذهب، عيار 21، عيار 24، سبائك 5/10/20/50/100 جرام، الأوقية + وقت آخر تحديث.
5. **رسم بياني** لنطاق سعر الذهب (شهر / سنة / 3 سنوات / 5 سنوات).
6. **قسم "من نحن"**: سنين الخبرة، تاريخنا، رسالة رئيس مجلس الإدارة، الرؤية والرسالة، القيم.
7. **خدماتنا**: خدمات الشركات، الجملة، التكرير.
8. **منتجاتنا**: كروت منتجات (صورة، اسم، زر "اشترِ الآن" برابط).
9. **مركز المعلومات**: التقرير اليومي، دليل الذهب، تحميل الكتالوج، التحقق من جودة الذهب.
10. **حاسبة زكاة الذهب** (تشتغل فعليًا بناءً على السعر الحالي).
11. **المدونة والأخبار**: قائمة مقالات + صفحة لكل مقال.
12. **قسم تحميل التطبيق** و **معرض صور** و **فوتر** (روابط، تواصل، سوشيال).
13. صفحات منفصلة: الرئيسية، من نحن، الخدمات، المنتجات، المدونة، الأخبار، تواصل معنا.
14. دعم **عربي وإنجليزي** (اتجاه الصفحة يتغير تلقائيًا).

## لوحة التحكم (/admin)

- تسجيل دخول آمن للمسؤول فقط.
- **الإعدادات العامة**: اسم الموقع، اللوجو، الألوان الأساسية، بيانات التواصل، روابط السوشيال.
- **النافذة المنبثقة**: تشغيل/إيقاف، النص، الرابط.
- **السلايدر**: إضافة / تعديل / حذف / ترتيب الشرائح.
- **الأسعار**: تعديل أسعار البيع والشراء لكل منتج، سعر الذهب والفضة بالدولار، وإضافة سجل أسعار للرسم البياني.
- **الأقسام**: تعديل نصوص "من نحن"، الخدمات، الرؤية، القيم.
- **المنتجات**: إضافة / تعديل / حذف مع رفع الصور.
- **المدونة والأخبار**: كتابة ونشر وتعديل المقالات.
- **رسائل التواصل**: عرض الرسائل اللي جاية من نموذج "تواصل معنا".
- رفع الصور مباشرة من اللوحة.

## مراحل التنفيذ
1. تفعيل Lovable Cloud (قاعدة بيانات + تسجيل دخول + تخزين صور).
2. بناء التصميم العام والصفحة الرئيسية بكل أقسامها.
3. الصفحات الداخلية + المدونة + حاسبة الزكاة.
4. لوحة التحكم وربط كل قسم بيها.
5. بيانات تجريبية جاهزة + مراجعة على الكمبيوتر والموبايل.

## نقاط محتاج تأكيدها
- اسم الموقع/العلامة التجارية اللي هنستخدمه (لو عندك لوجو ارفعه).
- الأسعار هتتحدث يدويًا من اللوحة، ولا عايز ربط بمصدر أسعار مباشر لاحقًا؟
- المتجر: الأزرار تودي لروابط خارجية (زي الموقع الأصلي) — ولا عايز سلة شراء ودفع داخل الموقع (مرحلة لاحقة)؟

## تفاصيل تقنية

- تخزين الصور في bucket عام للصور.
- الرسم البياني بـ recharts، والترجمة عبر حقول نصية بلغتين لكل عنصر.
