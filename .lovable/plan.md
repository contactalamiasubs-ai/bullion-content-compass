# رفع الموقع على هوستنجر مع دومين من نيم شيب

## مهم قبل البدء
الموقع ليس صفحات ثابتة فقط: فيه تسجيل دخول ولوحة تحكم وتحديث أسعار وصلاحيات تعمل على الخادم. لذلك يحتاج من هوستنجر خطة تشغّل **Node.js**:
- مناسبة: VPS، أو خطط Business / Cloud التي فيها "Node.js Web App".
- غير مناسبة: Single / Premium المشتركة (ستعمل الصفحات ولن تعمل لوحة التحكم والأسعار).

قاعدة البيانات والصور وحسابات العملاء تبقى كما هي على Lovable Cloud، فلا تُنقل أي بيانات.

## الخطوات
1. **تجهيز المشروع للتشغيل على Node.js**: إضافة إعداد بناء خاص بالخوادم العادية بجانب الإعداد الحالي، وأمر تشغيل `start`، دون تغيير شكل الموقع أو وظائفه.
2. **ملف إرشادات بالعربي** داخل المشروع يشرح:
   - رفع الكود عبر GitHub أو ملف مضغوط.
   - إضافة متغيرات البيئة في هوستنجر (رابط ومفتاح الخادم الخلفي العامّان، ومفتاح الذكاء الاصطناعي لتحليل الأسعار).
   - أوامر التثبيت والبناء والتشغيل (و PM2 + Nginx لو كانت VPS).
3. **ربط دومين نيم شيب بهوستنجر**: في Namecheap → Advanced DNS إضافة سجل A للـ `@` و `www` إلى IP الخادم في هوستنجر (أو تغيير الـ Nameservers لهوستنجر)، ثم تفعيل SSL مجاني من هوستنجر.
4. **تحديث روابط تسجيل الدخول**: إضافة الدومين الجديد لقائمة الروابط المسموحة في تسجيل الدخول بجوجل ورسائل استعادة كلمة المرور، حتى لا يفشل الدخول بعد النقل.
5. **فحص بعد الرفع**: الصفحة الرئيسية، الأسعار، المنتجات، دخول العميل، /admin، فحص السبيكة.

## ما لا أستطيع عمله بنفسي
الدخول لحسابك في هوستنجر أو نيم شيب؛ ستنفذ خطوتي الرفع والـ DNS باتباع الدليل، وأساعدك في أي خطأ يظهر.

## بديل أسهل (اختياري)
ترك الموقع على استضافة Lovable الحالية وربط دومين نيم شيب بها مباشرة؛ بدون خادم أو صيانة، مع SSL تلقائي.

## تفاصيل تقنية
- بناء TanStack Start بهدف Node (nitro preset `node-server`) عبر متغير بيئة، مع إبقاء هدف Cloudflare الحالي افتراضيًا.
- المتغيرات: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `LOVABLE_API_KEY`؛ مفتاح service role غير متاح للنقل، فالوظائف الإدارية التي تعتمد عليه (دعوة/حذف المستخدمين) قد تحتاج بديلًا وسأوضح ذلك في الدليل.
- إضافة الدومين الجديد إلى Redirect URLs في إعدادات المصادقة.
